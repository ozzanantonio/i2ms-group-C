## Initial Idea & Social Problem
Urban communities frequently deal with broken public infrastructure, such as non-functioning street lighting, cracked sidewalks, or damaged public benches. These issues impact citizen safety and neighborhood accessibility.

**UrbanFix** is a mobile application idea designed to empower citizens to quickly report and map these infrastructure defects in their neighborhood. The goal is to create a simple tool to document the problem with a photo and location, helping the community see what needs to be fixed.
